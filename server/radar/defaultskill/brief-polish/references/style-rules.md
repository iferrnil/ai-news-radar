# 写作规则（中文新闻简报）

这些规则改编自 Sepia 的中文校准与新闻写作规则（见 credits.md），只保留适用于简短科技简报的部分。它们描述的是「人写的新闻」常见的样子，不是检测器的阈值：单独一处不算问题，成片出现才是。

## 句子与段落

1. **长短交错。** 人写的新闻句长离散度明显更大。一段里允许有一个四五十字、用逗号连起几个分句的长句，后面跟一个十来字的短句。避免三句以上长度相近的排比。
2. **段落少而实。** 机器倾向于把内容切成很多短段落、每段一两句。简报一个话题一段，一段三到六句。不要每句单独成段。
3. **分句用逗号连接。** 中文新闻常用逗号把相关信息串成一句（「某公司周二发布了 X，上下文窗口提到 100 万 token，价格比上一代低一半」），而不是拆成三个短句。
4. **不写排比和对仗。** 「不仅……更……」「既……又……」「从 A 到 B，从 C 到 D」一篇最多一次。
5. **「不是……而是……」最多一次。** 用它来纠正一个真实存在的误解，而不是制造转折感。

## 用词

6. **具体胜过形容。** 写参数、价格、日期、谁发布了什么，而不是「性能大幅提升」「引发热议」。没有数字就写动作。
7. **程度副词不叠用。** 「非常」「十分」「极其」「显著」少用；人写的新闻「很」比「非常」常见得多，而且常常什么都不用。
8. **少用「X地」状语。** 「迅速地推出」「积极地布局」改成「很快推出」或直接删掉。
9. **少用名词化。** 「实现了对 X 的支持」→「支持 X」；「进行优化」→「优化」。
10. **引述动词默认「说」。** 「表示」「指出」「强调」「坦言」带有判断，只在真的需要那层意思时用，不要轮换着用来显得多样。
11. **连接词不串联。** 一段里「此外」「同时」「另外」「与此同时」「然而」加起来最多一个。上下文已经连贯时，什么连接词都不用。
12. **人称克制。** 不对读者说「你」，不写「我们可以看到」。

## 结构

13. **开头直接说事。** 第一句就是最重要的那件事，不要背景铺垫、不要「近日」「日前」开头的套话。
14. **不写总结段。** 不用「总的来说」「综上」收尾，不写「未来可期」「让我们拭目以待」。最后一件事说完即止。
15. **不用反问代替事实。** 「这意味着什么？」之后自问自答是典型的机器腔。
16. **不加没有依据的判断。** 原文没说的影响、意义、趋势，一律不写。

## 标点与格式

17. 中文标点用全角；英文、数字、产品名两侧的空格跟随输入。
18. 省略号用「……」，破折号用「——」，都不要多用。
19. 不用加粗强调整句，不用 emoji，不用小标题以外的 Markdown 装饰。链接标记 `[[n]](url)` 原样保留。
