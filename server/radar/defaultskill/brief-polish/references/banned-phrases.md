# 禁用与慎用词句

**禁用**（出现即改写或删除）：

- 开场：「在当今……的时代」「随着……的快速发展」「近年来，……备受关注」「让我们一起来看看」「本期简报为您带来」
- 过渡：「值得一提的是」「值得注意的是」「不难发现」「毋庸置疑」「众所周知」「事实上，」（句首套话用法）
- 收尾：「综上所述」「总而言之」「总的来说」「总之」「未来可期」「让我们拭目以待」「敬请期待」「这无疑……」
- 夸饰：「重磅」「炸裂」「震撼」「颠覆性」「革命性」「里程碑式」「史诗级」「王炸」「遥遥领先」「引爆」「刷屏」「火出圈」
- 空泛：「赋能」「助力」「打造……生态」「全方位」「多维度」「深度融合」「持续发力」「开启新篇章」「注入新动能」「迈出了重要一步」
- 自我指涉：「作为一个 AI」「以下是润色后的简报」「希望对你有帮助」

**慎用**（一篇最多一次，且必须有具体内容支撑）：

- 「不仅……更……」「不是……而是……」「既……又……」
- 「此外」「同时」「与此同时」「另外」「然而」
- 「标志着」「意味着」「凸显了」「彰显了」「进一步」
- 「非常」「十分」「极其」「显著」「大幅」
- 「表示」「指出」「强调」「坦言」（默认用「说」，或直接陈述）
- 「引发热议」「广受关注」「备受期待」——除非摘录里有具体的数字或反应

**替换示例**

| 机器腔 | 改成 |
|---|---|
| 值得注意的是，该模型在多项基准测试中表现出色。 | 它在 SWE-bench 上拿到 72%，比上一版高 9 个点。 |
| 此举标志着公司在 AI 领域迈出了重要一步。 | （删除；原文没有依据） |
| 该公司表示，新功能将进一步提升用户体验。 | 公司说新功能下周上线，先开放给付费用户。 |
| 总的来说，本周 AI 行业动态频繁，未来可期。 | （删除结尾段） |
